# PTF_LHA

PTF changes to Peral's LHA (workshop 3596653038). Peral's PBO is never edited: this
addon is a config patch that loads after it, so the changes apply to every LHA,
including ones already placed in missions. Without the LHA loaded, the addon skips itself.

## What it changes

| Change | How |
| --- | --- |
| Aircraft and amphibious spawners list the PTF variants only, and only classes that exist | `Aircraft[]` / `Amphibious[]` on `Peral_LHA` |
| PTF flag in the ship's "Unit Flag" slot | `hiddenSelectionsTextures[]` index 4 |
| Hull number 8 instead of a random digit each mission | `PTF_LHA_hullNumber`, painted by `fn_shipInit` |
| The CIWS mounts and SAM launchers no longer get AI crews, so the ship doesn't shoot at aircraft by itself | `turrets[]` on `LHA_Aft` and `LHA_house_1` |
| Ship lights show for every player, including players who join later | light switch actions call `fn_setLights` / `fn_localLights` |
| The two island light switches stay in step | `PTF_LHA_LightGroups` in config.cpp |
| Light switch names are spelled out properly ("Trun On Lights", "Main Hillway", "Hanger") | `UserActions` displayName |
| The spawner won't delete a vehicle that has someone aboard to make room for a new one | `fn_spawnerSelectVehicle` replaces `LHA_fnc_lha_spawner_selectVehicle`, then runs Peral's script |
| AI helicopters can land on any of the six deck spots, not just Peral's single pad aft | invisible helipads, `fn_deckServices` |
| ACE fuel (unlimited) and ammo at Peral's three deck refuel points, where the model's hoses come up from the catwalk | a coiled hose and a vehicle ammo box on the deck, `fn_deckServices` |
| The hangar is an ACE repair facility | markers on the hangar floors, `fn_repairMarkers` |
| Ship's 1MC: ten announcements (flight quarters, general quarters, away the landing force, reveille, taps...) played through the whole ship | ACE "Ship's 1MC" at the light switch panel at the foot of the island, or the Zeus module PTF LHA > 1MC Announcement; `fn_announce` |
| A logistics console in the hangar spawns PTF's crates, forklifts and flight deck equipment on the ship | ACE "Ship's Logistics" at the console against the port hangar wall; `fn_logisticsSpawn` |
| The spawner can replace a parked UH-1Y. ACE's fast-rope anchor bar, attached to every UH-1Y, used to count as something in the way | same function: ignores attached objects and removes them with the old vehicle |

Mission makers can still override the flag and hull number in Eden (the LHA's "Unit Flag"
and "Ship Number" attributes), and Zeus can still crew the turrets. Players can still take
them over with a UAV terminal.

## Deck services

Peral's refuel points are 13 to 39 m from the deck spots, beyond ACE's default 12 m
hose, so aircraft taxi to the hose, as Peral's own refuel action expects. Raise
`ace_refuel_hoseLength` in the server's ACE settings to reach parked aircraft. Rearming
has no such limit: players carry the ammo from the box.

ACE's "under a roof" repair-facility test doesn't work at sea (it starts its ray at the
player's height plus their eye height above sea level, already above the flight deck),
so the hangar uses ACE's other test: a marked object within 7.5 m. `fn_repairMarkers`
puts one on the hangar floor under each of Peral's hangar ceiling lights.

## Logistics console

PTF's Spawner computer spawns at map markers, which on a ship means the sea, so the
LHA has its own: a console in the hangar (ACE interaction, "Ship's Logistics") with
three menus.

| Menu | What | Where it appears |
| --- | --- | --- |
| Cargo | the crates on PTF's Spawner computer: small and large supply crates, vehicle ammo, fuel bladders | hangar floor beside the console |
| Hangar Equipment | forklifts (Atlas, Kalmar, Peral's) and the pallet jack | hangar floor beside the console |
| Flight Deck Equipment | A/S32A deck tractor, A/S32A-35 deck crane, helidolly | flight deck |

Crates and forklifts ride the port aircraft elevator up to the flight deck. A spot
must be clear (no vehicle, crate, prop or person on it) before anything spawns there;
the console tries each spot of its area in turn and says when all are taken. Zeus can
edit everything it spawns. Classes from mods that aren't loaded don't show up.

Peral's "Disable Spawners" ship attribute and his spawner whitelist module apply to
the console as they do to his aircraft and amphibious spawners.

## 1MC

The announcements are PTF_Sound's "navy" lines (`tools/sound_lines.json`, generated by
`tools/generate-sounds.py` with the same TTS voices as PTF_Sound), so Zeus can also place
them on any loudspeaker from PTF Loudspeakers (Navy). On the ship they play from five
ship sections at once, one announcement at a time.

## Why a patch and not a subclass

Peral's spawner and light scripts read their lists from the class named `Peral_LHA`
(`configFile >> "CfgVehicles" >> "Peral_LHA"`), not from the ship's own class. A
`PTF_LHA: Peral_LHA` subclass would still get Peral's lists, and missions would have
to swap ships to get any change.

## Multiplayer

The light switches send `PTF_LHA_fnc_localLights` to every machine, using one JIP entry
per ship and light group. The 1MC panel asks the server (`PTF_LHA_fnc_announce`), which
plays the sound on every machine with `say3D`. The logistics console asks the server
(`PTF_LHA_fnc_logisticsSpawn`), which spawns the object and answers the player with
`systemChat`. Missions with a remote-exec whitelist (`CfgRemoteExec` mode 1) must allow
them:

```cpp
class CfgRemoteExec {
    class Functions {
        class PTF_LHA_fnc_localLights { allowedTargets = 0; jip = 1; };
        class PTF_LHA_fnc_announce { allowedTargets = 2; };
        class PTF_LHA_fnc_logisticsSpawn { allowedTargets = 2; };
    };
    class Commands {
        class say3D { allowedTargets = 0; };
        class systemChat { allowedTargets = 1; };
    };
};
```

## If Peral updates the LHA

- New vehicle list entries in Peral's version won't show up here: this addon replaces the
  lists. Add them to `CfgVehicles.hpp`.
- `turrets[]`, `hiddenSelectionsTextures[]` and the light switch statements are copies of
  Peral's with PTF's changes. If Peral changes those, compare them again.
- The deck services, helipads, logistics console and its spawn spots sit at positions
  measured on Peral's current model (`PTF_LHA_Deck`, `PTF_LHA_Logistics`). If he
  reshapes the hangar or flight deck, run the test and check its screenshots.
- The spawner fix runs Peral's script file by path
  (`\Peral_LHA\scripts\spawner\fn_lha_spawner_selectVehicle.sqf`). If that file moves, the
  aircraft and amphibious spawners stop working until the path in config.cpp is updated.

## Testing

```bash
python tools/lha-test/run.py
```

It plays the LHA in single player with the full modset and the release build, checks every
change above, and screenshots the hangar with its lights off and on into
`.hemttout/lha-test/shots`. The check lines start with `LHATEST` in the RPT.

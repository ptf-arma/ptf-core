# PTF_Dress

USMC Service "A" uniforms per MCO 1020.34H, for the ranks PTF uses: Pvt to GySgt,
HR to HMC (corpsmen, per MCO 1020.34H chapter 8), WO1 to CWO5, and 2ndLt to Col. Built on Bohemia's Art of War parade uniform model.

Everything in `data/`, plus `cfgRankVehicles.hpp` and `cfgRankUniforms.hpp`, is
generated by `tools/generate-dress-uniforms.py`: change the script and rerun it
rather than editing them by hand.

To check a change in game, run `tools/review-dress-uniforms.py`. It loads a fixed
mission and writes screenshots to `.hemttout/dress-review/shots`, with no manual
steps. `tools/dress-review/probe_sheets.py` puts a labelled grid on the model for
reading sheet positions.

`--demo` runs a posed lineup instead, and `tools/dress-review/make_demo_image.py`
turns its screenshot into the labelled image for sharing.

The belt is the same for every rank (MCO 1020.34H para 3002).

Judge colour in daylight on real terrain. Exposure varies a lot by map and time.

Every rank sheet carries a PTF watermark in parts of the texture the model never
shows, to help prove where a ripped copy came from. The belt and cap sheets do not.
See `credits_and_license.txt` for the terms.

`ui/` holds the Arsenal icons, made from in-game shots by
`tools/dress-review/make_icons.py`. Rerun it after changing how a rank looks.

The uniforms have no ribbon rack by default: a rack should only ever be the wearer's
own. `tools/dress-review/rack_test` shows that one can be drawn per wearer at runtime
on the same uniform.
